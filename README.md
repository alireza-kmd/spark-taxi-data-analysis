# Taxi Data Analysis with Apache Spark

## Overview
Big data analysis of NYC taxi trip records using Apache Spark (PySpark) on Databricks.

## Dataset
- **Format:** Parquet
- **Content:** Taxi trip records including pickup/dropoff times, distance, fare, tips, and geographic zones

## Analysis Steps
1. Data loading from Databricks Volumes
2. Schema inspection
3. Column selection and filtering
4. Handling missing values
5. Data transformation
6. Descriptive statistics
7. Data aggregation and results analysis

## Technologies
- Python
- Apache Spark (PySpark)
- Databricks
- Parquet format
